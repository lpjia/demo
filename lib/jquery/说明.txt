jquery-migrate 是jQuery 版本兼容补丁，专门解决：老代码用新版 jQuery 报错、功能失效的问题
先引入 jQuery 主文件
再引入 jquery-migrate 兼容文件


jQuery 1.x / 2.x 用 migrate 1.x
jQuery 3.x 用 migrate 3.x
jQuery 4.x 用 migrate 4.x


非压缩版本的 jquery-migrate 才会在控制台打印警告信息
