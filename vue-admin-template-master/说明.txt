require('script-loader!file-saver')
是 Webpack 构建环境中 的模块导入语法，核心作用是：通过 script-loader 加载 file-saver 库，并以原生 <script> 标签的方式注入到页面中

动态创建一个 <script> 标签
把目标模块（这里是 file-saver）的源码注入到标签中
将标签插入到页面的 <head> 或 <body> 中
浏览器加载并执行该脚本，使模块的 API 暴露到 全局作用域（而非模块作用域）


为什么需要 script-loader？
file-saver 本身支持 模块化导入（ES6 import / CommonJS require），但在某些场景下，开发者可能需要
让 file-saver 的 API（如 saveAs）直接暴露在全局（比如老项目中没有模块化，或需要全局调用）, 也就是说在window挂载saveAs, window.saveAs
避免 Webpack 对 file-saver 进行打包（通过脚本注入的方式加载，而非打包进最终的 bundle.js）
此时，script-loader! 就起到了 “桥接” 作用：将模块化的库，以非模块化的原生脚本方式加载
