permission 表


id 主键ID
INT UNSIGNED  无符号整数类型
AUTO_INCREMENT  自增


name 权限名
数据库存 VARCHAR(20) 类型, string
必填字段, 前端必须传且不为空''


ename 英文名
数据库存 VARCHAR(50) 类型, string
必填字段, 前端必须传且不为空''
RoleMana:view
对应前端页面级或按钮级 组件


curId 权限id
数据库存 INT 类型 UNSIGNED, sql给默认值 DEFAULT 0
用工具函数自动转成look字符串


look 权限字符串, 方便人看
0-000000-00000-00000-00000-00000-00000
数据库存 VARCHAR(64) 类型, string
实际前端填写权限, 以字符串来填, 组合权限先转成number, 再转二进制


前4个字段, 必传
前端需要填look, 计算curId, 都传给后台, 拿这2个字段重新计算是否=
有父级时, 前端传parentId和parentLook, 传给后台, 拿这2个字段重新计算是否=


parentId 父级权限id
数据库存 INT 类型 UNSIGNED, sql给默认值 DEFAULT NULL
构建tree结构
值可以是null, 表示无父级


parentLook 父级权限字符串
非数据库字段


前端js支持的位运算, 符号位+31位数字
高6位, 最多2**6=64个模块, 页面级
低25位, 最多25种操作, 组件级(按钮级)
