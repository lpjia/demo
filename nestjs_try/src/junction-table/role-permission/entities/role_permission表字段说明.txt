role_permission 表, 作为中间表


id 主键ID
INT UNSIGNED  无符号整数类型
AUTO_INCREMENT  自增


role_id 角色id, 关联表role roleId
数据库存 VARCHAR(10) 类型, string
sql给默认值 DEFAULT ''


permission_id 权限id, 关联表permission permissionId
数据库存 VARCHAR(10) 类型, string
sql给默认值 DEFAULT ''


role 角色信息
非数据库字段, 表关联
role_permission 多对一 role


permission 权限信息
非数据库字段, 表关联
role_permission 多对一 permission
