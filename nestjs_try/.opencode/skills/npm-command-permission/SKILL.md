# 包管理器命令执行许可规则

## 规则

当需要执行以下包管理器命令时，必须严格遵守本规则：

- `npm`
- `npx`
- `yarn`
- `pnpm`
- `pnpx`

在执行**任何**上述命令之前，必须先使用 `question` 工具询问用户是否允许执行该命令。

## 要求

1. **必须询问**：在每次执行上述命令前，通过 `question` 工具向用户确认。
2. **等待许可**：只有在用户明确同意后，才能执行命令。
3. **禁止自动执行**：绝对不能在没有获得用户许可的情况下，直接运行上述命令。
4. **逐一询问**：即使多个命令作为工作流的一部分，每个命令都需单独获得许可。
5. **说明用途**：在询问时，简要说明该命令的作用和预期效果，以便用户做出知情决定。

## 询问示例

```text
即将执行命令: npm install express
用途：安装 express 依赖包
是否允许执行？
```

用户必须明确回答"是"或"允许"等肯定答复后，才能执行该命令。
